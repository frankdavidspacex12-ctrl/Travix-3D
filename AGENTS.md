# Instrucciones para asistentes de código (Travix-3D)

En **cada cambio** del proyecto (código, modelos, texturas, dependencias) sigue la skill
[`agents/skills/memoria-y-fluidez/SKILL.md`](agents/skills/memoria-y-fluidez/SKILL.md):
la app debe usar poca memoria, no cerrarse sola en celulares y no trabarse, sin sacrificar
calidad visual de más. Léela antes de escribir el cambio y revisa su lista antes del commit.
